# FoodsManager

FoodsManager es una aplicación de escritorio que permite a los restaurantes
administrar digitalmente sus productos, precios y disponibilidad. Los clientes
pueden consultar menús actualizados desde una sola aplicación.

## Tecnologías

- Java
- JavaFX
- SQLite
- JDBC
- Maven
- JUnit
- Git y GitHub

## Arquitectura

El proyecto utiliza el patrón Modelo-Vista-Controlador (MVC).
